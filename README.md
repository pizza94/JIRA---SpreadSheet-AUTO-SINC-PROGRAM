# Jira 이슈 → Google Sheets 자동 동기화 프로그램

사내 Jira 이슈 목록을 조회하여 Google Sheets 기반 QA·릴리스 체크리스트에
자동으로 등록하거나 기존 행을 갱신하는 Windows 데스크톱 프로그램입니다.

Electron과 Playwright를 사용하며, 사용자가 Chrome에서 직접 Jira에 로그인한
뒤 이슈 번호 목록과 대상 Google Sheets 탭을 지정하는 방식으로 동작합니다.

## 주요 기능

### Jira 조회

- 여러 Jira 이슈 일괄 조회
- 분류와 제목이 포함된 텍스트에서 Jira 번호만 자동 추출
- 중복된 Jira 번호 자동 제거
- 다음 정보 조회
  - 유형
  - Jira 번호
  - 고객사
  - 제목
  - 상태
  - 중요도
  - 담당자
- 설명, 상위 이슈, 라벨, 컴포넌트, 버전 등 상세 정보는 JSON으로 저장

다음과 같은 내용을 그대로 붙여넣을 수 있습니다.

```text
버그
[MS-12818] - [고객사] 용어 신규 팝업 항목 누락

개선
[MS-12807] - 결재현황 화면 개선
[MS-12811] - 변경분 하이라이트 표시
```

### Google Sheets 반영

- Google Sheets 링크와 대상 탭 이름으로 정확한 탭 선택
- 탭 이름 비교 시 공백 무시
- 메인 이슈 헤더 아래부터 참고사항 영역 전까지만 이슈 목록으로 인식
- 기존 Jira 이슈는 중복 등록하지 않고 원래 행 갱신
- 번호가 준비된 빈 이슈 행이 있으면 첫 빈 행부터 사용
- 기존 이슈가 없으면 번호가 없어도 헤더 바로 아래 빈 행부터 사용
- 사용 가능한 빈 이슈 행이 없으면 마지막 이슈 아래에 행 삽입
- Jira 번호에 실제 Jira 링크 적용
- 기존 테두리, 정렬, 드롭다운 및 셀 서식 유지
- 유형별 기존 색상 규칙 적용
  - 버그
  - 개선
  - 부작업
  - 새 기능
- 테스트자, SNAPSHOT, 참고사항 여부 등 사용자가 작성한 값 보존

### 고객사명 일관성

고객사명은 다음 정보를 종합해 결정합니다.

1. Jira 제목의 `[고객사]`
2. Jira 상위 이슈 제목
3. Jira 라벨과 컴포넌트
4. 대상 시트명
5. Jira 프로젝트

같은 고객사가 시트에 이미 존재하면 기존 표기를 재사용합니다.
`QA`, `ITMS`, `MetaStream`과 같은 일반 구분값은 고객사명에서 제외합니다.

### 테스트 일정

아래 일정은 선택적으로 입력할 수 있습니다.

- 테스트 배포일정(데드라인)
- 테스트 시작일
- 테스트 종료일

날짜 형식은 `YYYY.MM.DD`이며 실제 달력에 존재하는 날짜인지 검증합니다.
입력하지 않은 일정은 시트에서 변경하지 않습니다.

### 실패 로그

- 작업 실패 시 상세 로그 영역 자동 열기
- 화면 상단에 핵심 실패 원인 표시
- 전체 오류 출력과 일반 출력 표시
- 결과 폴더에 `failure-<작업>-<실행시각>.log` 저장

### 보안과 초기화

- Jira 비밀번호를 프로그램이 읽거나 저장하지 않음
- Chrome에서 사용자가 직접 로그인
- 프로그램 종료 시 다음 정보 삭제
  - Jira 로그인 세션
  - Google 로그인 세션 파일
  - Jira 주소와 이슈 목록
  - 시트 링크와 탭 이름
  - 테스트 일정 입력값
- 실행 결과 JSON, 화면 캡처 및 실패 로그는 결과 폴더에 유지

## 요구 사항

- Windows
- Google Chrome
- Node.js 20 이상
- 접근 가능한 Jira 서버
- 편집 권한이 있는 Google Sheets

## 설치

```powershell
npm.cmd install
```

## 개발 환경 실행

```powershell
npm.cmd run app
```

## Windows 무설치 EXE 빌드

```powershell
npm.cmd run dist:win
```

완성된 실행 파일은 다음 경로에 생성됩니다.

```text
dist/Jira-Sheets-Sync-<version>.exe
```

## 사용 방법

1. Jira 서버 주소를 입력합니다.
2. `Jira 로그인`을 누르고 열린 Chrome에서 직접 로그인합니다.
3. Jira 번호 목록 또는 분류·제목이 포함된 이슈 목록을 붙여넣습니다.
4. 작업 버전에 맞는 Google Sheets 링크를 입력합니다.
5. 대상 시트 탭 이름을 입력합니다.
6. 필요한 경우 테스트 일정을 입력합니다.
7. `조회 및 시트 반영`을 실행합니다.
8. 우측 결과 표와 상세 로그에서 처리 결과를 확인합니다.

## 공개 저장소 예시값

저장소에는 실제 사내 주소 대신 다음 예시값이 들어 있습니다.

```text
Jira: http://jira.example.local:8079/
Google Sheets: https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit
```

사용 환경에 맞는 값을 프로그램 화면에서 직접 입력하거나 기본 예시값을
수정해서 사용하세요.

## 지원하는 기본 시트 구조

메인 이슈 헤더는 다음 열을 기준으로 탐색합니다.

```text
번호 | 유형 | JIRA | 고객사 | 제목 | 상태 | 중요도 | 담당자
```

뒤쪽에는 테스트자, SNAPSHOT, 참고사항 여부 등의 열을 추가로 사용할 수
있습니다. `참고사항` 영역은 메인 이슈 목록의 종료 지점으로 인식합니다.

## 결과 파일

프로그램의 결과 폴더에는 다음 파일이 생성될 수 있습니다.

```text
<JIRA번호>.json
sync-<실행시각>.json
sync-<실행시각>.png
failure-<작업>-<실행시각>.log
```

이 파일들은 `.gitignore`에 의해 Git 저장소에 포함되지 않습니다.
